# 중간 구현 범위와 기말 개선 계획

중간보고 자료는 공개 서비스의 배포와 검증을 마친 뒤 실제 결과로 작성한다. 아래 계획은 구현 완료 기능이 아니며, 진행 결과에 따라 갱신한다.

## 중간 단계에서 완성할 범위

- Next.js 화면과 서버 API로 과제 등록·조회·수정·완료·삭제를 구현한다.
- 서버 입력 검증, SQL 매개변수 바인딩, 텍스트 출력과 브라우저별 데이터 분리를 확인한다.
- GitHub 공개 저장소와 PostgreSQL을 연결한 Vercel 공개 주소를 확보한다.
- 공개 환경의 실제 저장·재조회·사용자 분리와 재배포 후 데이터 유지를 검증한다.
- 검증 기록과 실제 화면을 남긴 뒤 편집 가능한 중간보고서와 발표 자료를 만든다.

## 기말까지 우선 진행할 개선

| 개선 | 목적 | 완료 판단 기준 |
| --- | --- | --- |
| 마감 상태 표시와 간단한 검색 | 과제가 늘어도 필요한 항목을 찾기 쉽게 한다. | 제목·과목 검색 및 마감일 기준 표시를 실제 데이터로 확인한다. |
| 모바일·키보드 사용성 점검 | 작은 화면과 키보드에서도 주요 기능을 사용할 수 있게 한다. | 가로 넘침 없이 입력·수정·삭제를 수행하고 초점 이동을 확인한다. |
| 오류 안내 보완 | 잘못된 입력이나 서버 연결 실패 시 사용자가 대응할 수 있게 한다. | 입력 오류와 DB 연결 실패의 안내가 구분되고 입력 내용을 보존한다. |
| 배포 환경 검증 보강 | 로컬과 공개 환경의 차이에서 생기는 문제를 줄인다. | PostgreSQL 및 재배포 후 유지, 다른 세션 접근 제한을 다시 확인한다. |
| 운영 및 종료 기록 | 무료 범위로 운영하고 과제 종료 후 자원을 정리한다. | 사용량과 오류를 점검하고 전용 배포·DB·저장소 삭제 절차를 확인한다. |

## 여유가 있을 때 검토할 항목

과제 CSV 내보내기는 쿠키 삭제 전에 본인 데이터를 보관하는 간단한 개선 후보이다. 계정 로그인과 기기 간 동기화는 현재 익명 쿠키 방식의 제약을 해결하는 확장 후보이지만, 인증·복구·권한 처리 범위가 커지므로 기말 필수 범위로 약속하지 않는다. 복잡한 알림, 외부 일정 연동과 유료 기능은 현재 계획에 포함하지 않는다.

## 중간보고에 명시할 현재 제약

현재 브라우저의 쿠키로 과제를 구분하므로 쿠키를 삭제하거나 다른 브라우저를 사용하면 이전 과제에 접근할 수 없다. 사용자 계정 로그인·복구·여러 기기 동기화는 구현하지 않았다. 공개 배포와 PostgreSQL 검증 결과는 실제 확인 후 별도 검증 기록에 반영한다.
